プライバシーポリシー

最終更新日：2026年11月23日

Case Workspace（以下「本アプリ」）における、利用者の情報の取り扱いについて定めます。本アプリは開発者本人が自身の業務のために作成したものであり、一般への配布は行っていません。

1. 取得する情報

本アプリは、利用者がGoogleアカウントへの接続を許可した場合に限り、次の情報にアクセスします。

  • Googleカレンダーの予定（google.com/auth/calendar.events）
    予定の日時とタイトルを読み取り、タスクの候補として表示します。利用者が完了操作を行ったとき、予定のタイトルを書き換えます。
  • Gmailのメール（google.com/auth/gmail.modify）
    スターを付けたメールの件名と差出人を読み取り、タスクの候補として表示します。利用者が完了操作を行ったとき、該当メールのスターを外します。

上記以外の情報は取得しません。メールの本文を保存することはありません。

2. 情報の保存場所

取得した情報および利用者が入力した内容は、利用者自身のパソコン内のファイルにのみ保存されます。開発者が運営するサーバーは存在せず、情報が外部へ送信されることはありません。

Googleへのアクセス許可を示す認証情報も、同じく利用者のパソコン内にのみ保存されます。

3. 第三者への提供

取得した情報を第三者へ提供、販売、共有することは一切ありません。広告目的での利用も行いません。

4. 情報の利用目的

取得した情報は、本アプリの画面にタスクの候補を表示すること、および利用者の操作に応じてカレンダーの予定やメールのスターを更新することにのみ利用します。他の目的には使用しません。

5. Google API サービスのユーザーデータに関する方針

本アプリによるGoogle APIから取得した情報の利用および他者への提供は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに準拠します。

6. 情報の削除

利用者は、本アプリの画面上で接続を解除することにより、保存された認証情報をいつでも削除できます。また、Googleアカウントの権限設定から本アプリのアクセス権を取り消すことができます。パソコン内のデータファイルを削除すれば、保存された内容はすべて消去されます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、Googleアカウントに登録された開発者の連絡先メールアドレス宛にお願いします。

8. 改定

本ポリシーの内容は、必要に応じて改定することがあります。改定した場合は、このページの最終更新日を変更します。
